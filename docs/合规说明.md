# 合规说明

**这不是法律意见。** 以下是基于公开法规条文的理解，用来说明本项目为什么设计成现在这样。如果你打算基于本项目做面向公众的服务，请咨询专业人士。

## 本项目的定位：个人使用的客户端

本应用只是一个软件，不提供任何在线服务：

| 设计 | 本项目 |
|---|---|
| 服务器 | **没有**。App 直接连接用户自己选择的模型平台 |
| API key | **用户自己申请、自己填写**。App 不内置任何 key，也不代付费用 |
| 账号 | **没有**。不注册、不登录 |
| 数据 | **不收集**。不统计、不埋点、不上传对话；key 存在系统安全存储里 |

在这种设计下，向用户提供生成式 AI 服务的是用户自己选择的模型平台（例如 DeepSeek），而不是本项目。

《生成式人工智能服务管理暂行办法》第二条规定：研发、应用生成式人工智能技术，未向境内公众提供生成式人工智能服务的，不适用本办法。

## 一旦做了下面任何一件事，定位就变了

- 搭一个中转服务器，帮用户省去填 key；
- 内置 key，或替用户支付模型费用；
- 做账号系统、云端保存对话；
- 做成网页版、小程序，或者上架应用商店并面向公众推广。

这时你就成了“服务提供者”，需要考虑的至少有：生成式 AI 服务的备案与登记、算法备案、应用商店的资质要求。备案主体通常需要是境内依法设立的法人，个人一般无法办理。

## 即使是个人客户端，本项目也做了的事

| 事项 | 做法 | 依据 |
|---|---|---|
| 家长在场 | 首次打开必须由家长确认四项，否则不能使用 | 面向中小学的生成式 AI 使用指南（2025）：小学阶段禁止学生独自使用开放式内容生成功能；各模型平台用户协议要求未成年人在监护人同意和陪同下使用 |
| 不收集儿童信息 | 没有账号、不上传、不统计；界面提醒不要输入姓名、学校、住址，拍照避开孩子的脸 | 《个人信息保护法》对不满十四周岁未成年人个人信息的特别保护 |
| AI 生成内容标识 | 学习界面底部始终显示“内容由 AI 生成，可能出错” | 《人工智能生成合成内容标识办法》 |
| 时长 | 默认 20 分钟提醒收尾，可调 | 《未成年人网络保护条例》关于监护人合理安排上网时间的要求 |
| 不做“拍照搜题” | 照片只识别成文字，AI 不直接给答案 | 教育部门对义务教育阶段“拍照搜题”类应用的限制方向 |
| 不使用他人商标 | App 名叫“慢慢想”，不使用模型厂商的名称 | — |

## 分发

- **Android**：GitHub Releases 发布 APK，用户自行安装。
- **iOS**：只能通过 App Store 或 TestFlight。TestFlight 有人数上限和有效期，不适合大规模分发；上架 App Store 会涉及上面说的资质问题。
- 请不要把本应用包装成“AI 老师服务”在国内大规模推广。
