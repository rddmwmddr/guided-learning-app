# 设计说明

这份文档记录每个设计决定是为了解决哪个实际问题，以及对应的实验结果。修改设计前请先读这里，避免重新踩一遍坑。

## 1. 提示词以提示词库为准

`assets/prompts/` 是从 [提示词库](https://github.com/syhdeclan/guided-learning-prompts) 同步过来的，不在本仓库直接修改。本应用需要的额外要求（念给孩子听、看进度记录、何时结束）写在 `lib/core/tutor_engine.dart` 的 `appRules` 里，附加在提示词后面。

这样分工的好处是：老师和教研人员只需要关心提示词库；App 只是提示词的一种用法。

## 2. 照片直接交给老师看

**曾经的做法**：照片先识别成文字，家长核对后教学只用文字。理由是千问 App 里一发图片就跳进内置解题流程。

**为什么改了**：那是千问 App 的入口问题，在我们自己的 App 里不存在；而转成文字会丢掉几何图、绘本插图、实物照片里的信息。家长也反馈多核对一步很麻烦。

**现在的做法**：

- 照片（最多 3 张）随学习材料每一轮都交给老师，老师自己看图。照片在请求的固定前缀里，平台的上下文缓存能命中，重复发送的费用很低。
- 记录员看不到图。实测记录员会把第一个小步骤（“数出红圆个数”）误当成原题并锁定。所以开始时让能看图的模型后台写一段照片内容摘要，只给记录员用；改后记录员写出的原题是“看图列式计算苹果比梨多几个”。
- 照片和对话保存在本机的“对话记录”里，可以随时删除。

## 3. 进度记录：解决长对话兜圈子

**问题**：DeepSeek 深度思考在真实长对话里会兜圈子，一直抛问题，但忘了为什么问、这个问题和原题有什么关系。

**做法**：

1. 每轮只把最近 12 条对话原文交给老师，更早的由进度记录承接；
2. 进度记录包含：原题要解决的、孩子自己已经确认的、现在的小目标（及其与原题的关系）、卡点、提示级别、是否完成；
3. 提示词后附加【主线】要求：问题服务于小目标，小目标服务于原题；同一个小目标三轮没进展就加一级提示或示范；每三四轮用一句话告诉孩子走到哪儿了。

**一个失败的版本**：最初让老师在每次回复末尾自己写记录，App 把它藏起来。实测 20 轮里有 **12 轮漏写**，因为模型会模仿历史消息，而历史消息里的记录被去掉了。

**现在的版本**：记录由单独的“记录员”调用生成（不开思考，几秒钟）。它在孩子听老师说话时后台进行，不增加等待时间。改版后三个场景 0 次失败。

**原题不可改**：记录员第一次写下“原题要解决的”之后，代码层面不再允许它修改，防止主线被改丢。

### 对照实验（2026-10-30，`tool/long_dialogue.dart`）

模型：deepseek-v4.1-flash，开启思考。模拟孩子：xiaomi/mimo-v2.6-pro，设定为反应慢、会答错、会走神。

| 场景 | 粘贴提示词 | 本应用（记录员版） |
|---|---|---|
| 二年级退位减法 | 20 轮内讲完，中途插入两次“给家长的话” | **10 轮完成**。孩子说“我有点乱了”时改用“3 捆小棒和 5 根单的”示范（提示级别 3），主线始终是原题 |
| 五年级分数两问 | 第 13 轮讲完，**之后 7 轮反复说再见** | 第一次 24 轮未结束：孩子做对迁移题后又回头逐步复查原题。补充【何时结束】规则和 18 轮兜底后重跑两次：**12 轮、22 轮，都自然收尾** |
| 三年级科学 | （未测） | **9 轮完成**：观察 → 排除猜想 → 哈气实验 → “我认为……因为……” → 迁移到冰饮料瓶 |

模拟测试不等于真实孩子，以上只能说明方向。真实使用的结果请记录到提示词库的平台复查里。

## 4. 回合制语音，而不是实时通话

**录音的坑**：识别服务上一回合没释放就开始下一回合，会报 `error_busy`；结束信号丢失时会一直停在录音状态。现在每一回合有编号，迟到的旧回调一律忽略；遇到忙会等一下重试一次；点停止后最多 1.5 秒一定结束，任何情况下 70 秒必定结束；iOS 上语音合成和识别共用一个音频会话。


**问题**：能视频通话的 App（豆包）用的是低延迟的小模型，引导能力弱。实时语音和强模型本来就矛盾。

**做法**：本项目的教法本来就是回合制的：问一个问题，停下等孩子回答。所以用回合制语音：

孩子说 → 识别成文字 → 开了深度思考的模型 → 系统语音合成，用比平常慢的语速念出来 → 自动开始听

- **停顿时长**：默认孩子停顿 4 秒算说完，可调到 2–8 秒。依据是“等待时间”研究：给足等待时间，孩子的回答更长、“不知道”更少。
- **语速**：默认 0.42，比正常慢。

## 5. 结束

- 记录员标记“是否完成”，或家长点“请老师收尾”，或老师已经说了 18 轮：老师收尾。
- 老师收尾后，再给孩子一次说话的机会，然后显示“今天就到这里”。
- 家长可以点“还想接着学”。
- 到了设定时长（默认 20 分钟）会提醒家长，但不强制打断。

## 6. 不念出来的东西

模型偶尔会编出“（家长旁白：……）”，或在对话中间写“（给家长的话：……）”。`cleanSpoken` 会把括号里含“家长、旁白、备注、动作、停顿”的部分去掉，再交给语音合成。正常的括号内容（如“三个十（也就是三十）”）保留。
